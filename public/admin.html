How payments are confirmed

Every order gets a unique amount (e.g. ₹49.37). When any of the methods below reports a credit of that exact amount, the customer's question unlocks automatically. Use one or more methods. They can safely run together, because duplicate reports are ignored.

1 · BharatPe app notification (Android)

  1. Install MacroDroid (or Tasker / "Notification Forwarder") on the phone with the BharatPe app.
  2. Trigger: Notification received → app BharatPe (also add PhonePe Business / Paytm for Business if you use them).
  3. Action: HTTP Request → POST to the notification URL, content type JSON, body:
    {"app":"bharatpe","title":"[notification_title]","text":"[notification]"}
  4. Allow MacroDroid notification access and turn off battery optimisation for it.

2 · Bank / BharatPe SMS (Android)

  1. Install the open-source SMS Forwarder (F-Droid / GitHub bogkonstantin/android_income_sms_gateway_webhook), or use MacroDroid with an SMS received trigger.
  2. Sender filter: BHRTPE, BharatPe or your bank (e.g. HDFC, UNITY).
  3. POST to the sms URL with body {"from":"%from%","text":"%text%"}.

3 · E-mail alerts (Gmail, no phone needed)

If BharatPe or your bank e-mails you for each payment, open script.google.com, create a project, paste this script and add a time-driven trigger every 1 minute on forwardPayments.
