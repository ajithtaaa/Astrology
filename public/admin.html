Chats

For safety, only approved chats can confirm payments. Send any message in the chat or channel (or forward a payment notification there). It appears here, and you click Approve.

Setup – pick the option that matches your forwarder

A · Your phone app sends notifications through your own bot

  1. Telegram → @BotFather → /newbot. This creates a second bot just for the website, e.g. JeevithaPayBot. Copy its token, paste it on the left and click Connect.
  2. Create a private Telegram channel (e.g. "Payments"). Add both bots as admins: your "notifications forwarder" bot and the new website bot.
  3. In your forwarder app, set the chat ID to that channel (channel IDs start with -100). Your forwarder bot posts into the channel and the website bot reads every post.
  4. Post any test message in the channel, then approve the channel on the left.

Why two bots? Telegram never sends a bot its own messages, and bots can't read other bots in groups. In a channel where it's an admin, though, a bot sees every post.

B · Notifications arrive from someone else's bot (you have no token)

  1. Create the website bot as in A.1 and connect it.
  2. Check whether your forwarder app can send to a channel or custom chat ID. If it can, use A.2–A.4.
  3. If it can only message you privately, use the Webhook setup tab instead. Most forwarder apps can also POST to a URL.

C · Test it

Post Rs.1.00 received via UPI. UTR 123456789012 in the approved channel. A ₹1.00 row should appear under Payments received within a few seconds. In a private chat with the website bot, it also replies with the result.

How payments are confirmed

Every order gets a unique amount (e.g. ₹49.37). When any of the methods below reports a credit of that exact amount, the customer's question unlocks automatically. Use one or more methods. They can safely run together, because duplicate reports are ignored.

1 · BharatPe app notification (Android)

  1. Install MacroDroid (or Tasker / "Notification Forwarder") on the phone with the BharatPe app.
  2. Trigger: Notification received → app BharatPe (also add PhonePe Business / Paytm for Business if you use them).
  3. Action: HTTP Request → POST to the notification URL, content type JSON, body:
    {"app":"bharatpe","title":"[notification_title]","text":"[notification]"}
  4. Allow MacroDroid notification access and turn off battery optimisation for it.

2 · Bank / BharatPe SMS (Android)

  1. Install the open-source SMS Forwarder (F-Droid / GitHub bogkonstantin/android_income_sms_gateway_webhook), or use MacroDroid with an SMS received trigger.
  2. Sender filter: BHRTPE, BharatPe or your bank (e.g. HDFC, UNITY).
  3. POST to the sms URL with body {"from":"%from%","text":"%text%"}.

3 · E-mail alerts (Gmail, no phone needed)

If BharatPe or your bank e-mails you for each payment, open script.google.com, create a project, paste this script and add a time-driven trigger every 1 minute on forwardPayments.
